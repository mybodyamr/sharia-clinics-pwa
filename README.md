# عيادات الجمعية الشرعية — PWA Demo

## التشغيل
- افتح `index.html` مباشرة للتجربة الأساسية.
- لتجربة PWA وService Worker، استخدم Localhost أو HTTPS، مثل VS Code + Live Server أو `python -m http.server 8080`.

## حسابات التجربة
- Admin: `admin` / `admin123`
- Doctor: `doc1` / `123456`
- Reception: `reception` / `123456`

## التخزين
كل البيانات محفوظة في `localStorage`، والجلسة في `sessionStorage`.

## التذكرة والـQR
- التذكرة تحتوي على QR مربع حقيقي.
- شاشة الاستقبال فيها تشغيل الكاميرا لمسح QR، مع إدخال يدوي كخطة بديلة.
- زر حفظ التذكرة يصدر PNG كامل للتذكرة.
- زر الطباعة يجهز صورة التذكرة للطباعة، ويمكن اختيار الحفظ كـPDF من نافذة الطباعة.

## قواعد منع تكرار الحجز
- يمنع التكرار عندما يتطابق الاسم + رقم الهاتف معاً في نفس العيادة وفي نفس اليوم.
- نفس رقم الهاتف مع اسم مختلف: مسموح.
- نفس الاسم مع رقم مختلف: مسموح.
- LocalStorage لا يزامن بين الأجهزة. منع التكرار عبر أجهزة مختلفة يحتاج قاعدة بيانات مشتركة مثل Supabase.

## ملاحظة أمنية
هذا إصدار Frontend-First تجريبي. لا يمكن جعل QR غير قابل للتزوير بشكل حقيقي عندما يكون مفتاح التوقيع ومنطق التحقق داخل JavaScript في المتصفح. عند الربط الحقيقي يجب نقل التوقيع والتحقق إلى Backend/Edge Function مع مفتاح سري غير مكشوف، وربط المستخدمين بالمصادقة وقواعد الصلاحيات.
